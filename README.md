# 9-nine- Episode 3 简体中文补丁

适用于 Steam 正版《9-nine-：春色春恋春熙风》（*9-nine- Episode 3*）的外挂式简体中文补丁。


## 补丁内容

使用 Hydrogen 进行翻译，以官方日语（jp）为基准、交叉核对官方英文（en），译校了全部 49 个剧本共 11,935 行正文及全部 13 处选项。

针对中文母语语序进行意译润色，世界观专有名词与店名（`Artifact`、`Overlord`、`The Order`、`Betrayer`、`Stigma`、`Ambrosia`、`Sephirot`、`Rig Veda`、`Valhalla Society`、`Gate`、`Nine Ball`、`MockDonald's`）保留英文，并修正了官方繁中说话人标签错漏（如 `CN河本`）。

注：包含全部正文与 R18 场景文本在内的 11,935 行均已完成简体中文译校。

## 安装与卸载

- **安装**：运行 `dist/9-nine-ep3-sc-patch/安装补丁.bat`，或将 `video` 文件夹复制到游戏根目录。若此前保存过其他语言设置，可在菜单 `Language -> Simplified Chinese` 或 Config 中切换。**安装脚本默认游戏安装在C盘，如果安装在其他盘符请先将补丁复制到游戏根目录**
- **卸载**：运行 `卸载补丁.bat`，或删除游戏目录下的 `video` 文件夹。
